# Jetpack Compose Basics

A comprehensive collection of **Jetpack Compose** component examples built with **Material 3**, organized as a learning reference for Android UI development.

## 📂 Project Structure

Each folder demonstrates a specific Compose component or concept:

| Folder | Component | Description |
|--------|-----------|-------------|
| `a_CoreComponents` | Text, TextField, Buttons, Image | Core building blocks — text rendering, input fields, button variants, and image display |
| `b_LayoutComposables` | Row, Column, Box | Layout composables for arranging UI elements |
| `c_BottomSheet` | BottomSheet | Modal and standard bottom sheets |
| `d_Cards` | ElevatedCard | Material 3 card components |
| `e_CheckBox` | CheckBox | Single and multi-select checkboxes |
| `f_InputChips` | InputChip | Chip-based input components |
| `g_dialogBox` | AlertDialog | Dialog box implementations |
| `h_ExtendedFAB` | ExtendedFloatingActionButton | Extended floating action buttons |
| `i_Menus` | DropdownMenu | Dropdown and context menus |
| `j_Scaffold` | Scaffold | Scaffold layout with an Instagram-style example |
| `k_NavigationDrawer` | NavigationDrawer | Modal and permanent navigation drawers |
| `l_ProgressIndicator` | CircularProgressIndicator, LinearProgressIndicator | Determinate and indeterminate progress indicators |
| `m_PullToRefresh` | PullToRefresh | Pull-to-refresh gesture handling |
| `n_SearchBar` | SearchBar | Material 3 search bar |
| `o_SegmentedButton` | SegmentedButton | Single and multi-select segmented buttons |
| `p_Slider` | Slider | Continuous and discrete sliders |
| `q_SnackBar` | Snackbar | Snackbar notifications via `SnackbarHost` |
| `r_Badges` | Badge | Icon and navigation badges |
| `s_Switch` | Switch | Toggle switches |
| `t_DatePicker` | DatePicker | Material 3 date picker dialogs |
| `u_TimePicker` | TimePicker | Material 3 time picker dialogs |
| `v_BottomNavigationBar` | NavigationBar | Bottom navigation with icons and labels |
| `w_TopAppBar` | TopAppBar | Top app bar variants (small, medium, large) |

## 🛠️ Tech Stack

- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Design System:** Material 3
- **Min SDK:** See `build.gradle.kts`

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/RishabhRajGupta/JetpackComposeBasics.git
   ```
2. Open in **Android Studio** (Ladybug or later recommended).
3. Sync Gradle and run on an emulator or device.
